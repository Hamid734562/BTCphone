# BTCPhone — پروژهٔ آزمایشی اندروید

این ZIP شامل یک پروژهٔ پایهٔ اندروید و گردش‌کار GitHub Actions برای ساخت APK است.

**مهم:** این نسخه فقط برای بررسی مسیر ساخت و نصب APK است؛ استخراج واقعی بیت‌کوین، اتصال Stratum به استخر، ارسال share و پرداخت را پیاده‌سازی نمی‌کند. فایل APK از قبل داخل ZIP نیست؛ گردش‌کار GitHub باید آن را بسازد. ساخت این پروژه در این محیط کامپایل و تأیید نشده است.

## فایل APK پس از ساخت
در مخزن GitHub به بخش Actions بروید، اجرای موفق «Build Android APK» را باز کنید و از قسمت Artifacts فایل `BTCPhone-debug-apk` را دریافت کنید. داخل آن `app-debug.apk` قرار دارد.
